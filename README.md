### 🌟 Projects

**📈 Optimal Control of Timber Harvesting**
`MATLAB` `Optimal Control` `Numerical Methods`
Modelled the trade-off a timber farm faces between reinvesting harvest revenue and taking immediate profit. Applied Pontryagin's Maximum Principle to prove the optimal strategy is bang–bang, derived a closed-form switching time, and verified the result numerically using a Forward–Backward Sweep method with RK4 integration.

**🧰 SkillHive — Platform for Local Services**
`React` `Node.js` `MySQL` `Docker`
Team-built web platform connecting local service providers with customers. Worked on the front-end interface and MySQL integration, and contributed to reviews, feedback management, notifications, input validation and user authentication.

**🗂️ Workshop Registration System**
`Java` `MySQL` `JDBC`
Designed a relational database schema for workshops and participants, and built a Java application with full CRUD operations connected via JDBC.
